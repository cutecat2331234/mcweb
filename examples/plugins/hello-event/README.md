# Hello/Event reference plugin

This installable CE plugin demonstrates a strict manifest, typed settings,
after-commit domain event handling, plugin-owned event publication, translation
contributions, and a schema-rendered admin page.

```sh
bin/mcweb-plugin validate examples/plugins/hello-event --json
bin/mcweb-plugin test examples/plugins/hello-event --json
bin/mcweb-plugin build examples/plugins/hello-event --json
```
