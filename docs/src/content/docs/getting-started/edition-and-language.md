当前站点属于 **McWeb CE 社区版**。CE 是共享平台层，包含账户、社区、商城、Minecraft 集成、网站 CMS、工作人员审核、运维和可信插件能力。

## 版本边界

| 能力 | CE 文档是否适用 |
| --- | --- |
| 独立个人中心、统一通知、资料、两步验证、恢复和数据导出 | 是 |
| 社区、附件、举报复议与申诉、审核与工作人员案件 | 是 |
| 商城、订单、支付和对账 | 是 |
| Minecraft 身份、Hostd、节点、托管世界备份恢复和资源包 | 是 |
| 网站 CMS、内容回收与保留、后台任务和嵌入式 Sidekiq 控制台 | 是 |
| 应用、可信插件、REST API 与 Webhook | 是 |
| EE 实时频道、聊天、企业身份组 | 否 |
| EE-PVP 申请、测试、Tier、排行和赛季 | 否 |

版本不匹配时，不要照搬本网站没有列出的设置或操作。请改用安装包随附的对应版本文档站。

## 应用界面语言

McWeb 支持简体中文和英文。使用界面上的语言切换入口，或在“个人中心 → 编辑个人资料”修改界面语言；登录时保存的选择会更新账户偏好，并用于账户、论坛、商城和管理后台等入口。

未登录时，界面可能采用先前选择或浏览器语言。看到英文不一定表示站点缺少简体中文，先检查当前语言选择。用户正文、官网文章、插件自带文字和外部页面不会因为切换界面语言而自动翻译。

## 文档语言

简体中文是默认语言，使用 `/docs/` 下的无前缀地址。英文位于 `/docs/en/`，按页面逐步翻译。

英文页面缺失时，文档站会显示默认简中内容并标明这是回退内容。回退页不表示英文翻译已经完成；命令、路径和配置键仍保持原样。

文档站的语言选择与业务应用中的界面语言分开使用。需要中文说明时进入 `/docs/`；需要英文时使用文档页首语言入口或 `/docs/en/`。
