桌面端左侧是角色分类侧栏，右侧显示当前页面目录。移动端通过页首菜单打开侧栏；页面目录会折叠为正文上方的下拉入口。

## 搜索

页首搜索在浏览器中查询随构建生成的本地索引，不会把查询发送给第三方搜索服务。可使用页面标题、字段名称、错误提示、命令或配置键搜索。

## 深链

每个标题都有稳定锚点，可以复制包含 `#` 的地址直接指向某一步。文档构建会检查站内页面和标题锚点，失效链接会使构建失败。

## 求助时提供什么

请同时提供：

- 当前产品版本（CE、EE 或 EE-PVP）和发布版本号；
- 页面地址与操作角色；
- 界面显示的错误码或完整错误文本；
- 发生时间和可安全公开的请求标识；
- 是否可以稳定复现，以及是否已经发生不可逆操作。

不要在工单或聊天中发送密码、会话 Cookie、API 密钥、Webhook 密钥、私钥或完整凭据配置。
