系统任务页显示运行模式、队列快照、工作进程心跳、排队量、失败和可用的人工任务。Sidekiq 控制台和人工恢复入口都需要单独权限。

## 排查顺序

1. 先确认队列快照是否可用，以及工作进程心跳是否新鲜。
2. 查看失败任务的类别、首次/最近时间和重试状态，避免只看总数。
3. 对照运行指标检查请求错误、任务失败和队列利用率是否同时异常。
4. 只有在任务目录明确注册且当前用户获得授权时，才执行人工任务。

## 可恢复人工任务

人工重新打开或恢复操作必须由服务端任务注册表提供，不能从任意类名或用户输入动态执行。提交前核对作用域、参数和幂等键；执行后根据运行记录确认结果，不要因为浏览器超时直接重复提交。

反复失败时停止重试，保留任务标识、错误码和相关时间窗口，再转入故障处理。
