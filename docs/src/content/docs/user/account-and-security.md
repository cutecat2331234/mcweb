登录后从账户侧栏进入资料、安全、登录设备和数据导出页面。系统会根据你的权限与账户状态显示可用操作。

## 资料和密码

- 资料页用于维护公开显示名称和界面语言。
- 修改密码前需要重新确认当前身份；成功后，已有登录会话可能按站点策略失效。
- 邮箱变更需要完成新地址验证。在验证完成前，界面会显示待处理状态。

## 两步验证与恢复码

在“安全”中开始设置，使用验证器扫描二维码并输入一次有效验证码。确认成功后立即离线保存恢复码；恢复码只能用于无法使用验证器时的单次恢复。

重新生成恢复码会使旧恢复码失效。关闭两步验证或完成账户恢复时，按页面要求再次验证密码或安全代码。

## 登录设备

“登录设备”列出当前账户的活动会话。撤销其他设备不会替代修改已泄露的密码；怀疑凭据泄露时，应先修改密码，再检查并撤销未知会话。

## 数据导出

数据导出是异步、私密且有时效的归档。提交后可查看处理状态；成功后在过期前下载，失败任务可按界面提供的操作重试，已不需要的归档可以撤销。

导出归档可能包含个人信息。下载后请保存在受保护位置，不要转发公开链接。
