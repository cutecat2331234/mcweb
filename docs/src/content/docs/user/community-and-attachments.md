从应用导航进入“论坛”（`/app/forum/latest`），使用分区、主题、回复、标签、搜索、书签、关注、草稿和私信。你能看到的内容取决于登录状态、分区权限、内容状态和工作人员规则。

## 发布内容

创建主题或回复时，先选择正确分区并填写必填字段。提交后如出现错误，先刷新主题列表确认内容是否已创建，再决定是否重试，避免重复发布。

编辑、删除、关闭或重新打开自己的内容受站点时间窗口和权限控制。工作人员操作会留下相应审计或状态记录。

## 附件

附件上传会检查类型、大小、图片解码和安全扫描。文件可能依次处于处理中、可用、隔离或拒绝状态；隔离文件不会对普通用户开放。

不要反复上传被拒绝的文件。请根据界面错误检查格式和大小；若安全扫描持续不可用，请联系管理员并提供发生时间和请求标识。

## 通知与可见性

站内消息集中在[账户通知](/docs/user/account-and-security/#统一通知)，论坛的订阅和邮件选项在“偏好”中管理。静音主题、拉黑或忽略用户会影响你看到的内容或互动，但不会绕过工作人员留存、证据和安全规则。

关注主题、分区或标签时，通知级别决定哪些更新进入通知流；“关注邮件”控制新动态是否
立即发送邮件。摘要会定期汇总未读社区通知，选择“无”即可关闭摘要。已保存的搜索可在
偏好设置中重命名、删除或导出 OPML。

## 举报与处理结果

在具体内容或用户资料的“举报”入口提交问题，再到“我的举报”查看状态、补充事实或撤回仍待处理的举报。不要在公开回复中发布私密证据或要求他人重复举报。

已结举报的复议、受影响用户的处置申诉和证据附件操作，见[举报、复议与申诉](/docs/user/reports-and-appeals/)。撤销申诉决定不会自动恢复内容或解除其他独立处置。
