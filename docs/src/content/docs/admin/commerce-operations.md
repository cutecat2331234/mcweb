商城后台只显示当前 CE 版本已经注册且当前角色有权使用的入口。操作前先确认目标订单、
支付模式和当前状态；页面显示的校验错误、安全警告及精确确认短语优先于本文的一般步骤。

## 商城功能与配送

在 **商城 → 设置** 中启用或关闭已安装的商城子功能。关闭功能不会自动删除既有订单或
历史记录。实体配送启用后，可为每种方式配置唯一代码、显示名称、费用以及最短和最长
预计天数；保存前检查天数顺序和金额单位。

## 库存与财务

库存页显示可售、预留和已售数量以及不可变库存流水。不要直接修改数据库来纠正库存；
使用页面提供的调整动作并记录原因。财务页根据已持久化的订单、支付、退款、税费和发票
快照汇总，不能替代支付渠道的结算报表。

## 支付、争议与对账

支付操作页用于查看本地支付状态和可用的恢复动作；争议与逾期支付页面显示需要工作人员
处理的当前案件。支付对账按完整 UTC 日期读取渠道数据，记录运行状态和差异，但不会修改
渠道资金、订单、支付或退款。

每日任务会处理最近完成的 UTC 日期。手动对账只适用于页面允许的日期，并要求独立权限、
未过期令牌和页面给出的精确确认短语。提交后在运行历史中检查 pending、running、failed 或
completed 状态，先处理配置或渠道错误，再请求另一轮。完整渠道配置与安全边界见
[支付渠道配置与对账](/docs/operations/payment-provider/)。
