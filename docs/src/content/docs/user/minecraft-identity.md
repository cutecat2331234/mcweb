从“个人中心”进入“Minecraft 账户”（`/app/minecraft/link`）。默认绑定流程是在游戏内执行站点显示的绑定命令，再把一次性验证码提交到网页。

## 绑定与主账号

1. 在受支持的服务器中执行页面给出的绑定命令。
2. 在有效期内把验证码填入网页。
3. 绑定成功后，在账户列表核对名称、身份类型、UUID 和主账号标记。

验证码过期、已使用或来自其他账户时不会建立绑定。不要向他人发送绑定验证码。

主账号是默认展示和使用的已绑定身份。切换方式取决于站点当前策略：

- 立即生效：在允许的冷却时间后选择新的主账号。
- 工作人员审批：填写理由提交申请，在页面查看目标、状态和失效时间；仍待处理时可取消申请。
- 仅管理员代切换：不能自行切换，需要联系管理员说明原因。

已有申请、冷却未结束或目标绑定已经变化时，页面会提示当前限制。切换主账号不会自动改写历史记录创建时所使用的 Minecraft 身份。

## 皮肤与缓存

页面会显示当前缓存皮肤及刷新状态。刷新是受限操作，短时间重复请求可能进入冷却。外部皮肤源不可用时，系统会保留可用缓存或显示默认头像，而不是暴露上游错误详情。

## 解除绑定

解除绑定前核对目标，并按页面提示输入该 Minecraft 账号名称。解绑会影响以该身份为依据的展示和集成，涉及该绑定的待审主账号申请也会取消。

主账号本身不是一概禁止解绑：解除当前主账号后，若还有有效绑定，系统会选出继任主账号；没有剩余绑定时则不再有主账号。完成后重新检查账户列表。若页面报告其他业务限制、记录已变更或操作过于频繁，先处理提示，不要反复提交旧页面。

资源包和商城贴图由管理员/运维配置，参见 [Minecraft 资源包与商城贴图](/docs/operations/minecraft-resource-packs/)。
