当前站点属于 **McWeb CE 社区版**。CE 是共享平台层，包含账户、社区、商城、Minecraft 集成、网站 CMS、工作人员审核、运维和可信插件能力。

## 版本边界

| 能力 | CE 文档是否适用 |
| --- | --- |
| 账户、资料、两步验证、恢复和数据导出 | 是 |
| 社区、附件、审核与工作人员案件 | 是 |
| 商城、订单、支付和对账 | 是 |
| Minecraft 身份、Hostd、节点和资源包 | 是 |
| 网站 CMS、应用、插件、REST API 与 Webhook | 是 |
| EE 实时频道、聊天、企业身份组 | 否 |
| EE-PVP 申请、测试、Tier、排行和赛季 | 否 |

版本不匹配时，不要照搬本网站没有列出的设置或操作。请改用安装包随附的对应版本文档站。

## 语言策略

简体中文是默认语言，使用 `/docs/` 下的无前缀地址。英文位于 `/docs/en/`，按页面逐步翻译。

英文页面缺失时，文档站会显示默认简中内容并标明这是回退内容。回退页不表示英文翻译已经完成；命令、路径和配置键仍保持原样。
