## 按角色进入

- [用户指南](/docs/user/account-and-security/)：个人中心与通知、账户安全、Minecraft 身份、社区、附件、商城与支付。
- [工作人员指南](/docs/staff/workspace/)：审核队列、案件、举报复议与申诉、证据和受权限控制的处置。
- [管理员指南](/docs/admin/roles-permissions-settings/)：角色权限、系统设置、网站 CMS、应用和插件。
- [运维指南](/docs/operations/backup-release-rollback/)：部署、整站及世界备份恢复、Hostd、节点、任务、指标和支付渠道。
- [插件开发](/docs/plugin-development/getting-started/)：Developer Mode、SDK、REST API 和插件市场运维。

## 适用范围

本网站描述当前 CE 社区版的使用方法。功能是否显示，还取决于站点是否启用该功能、你的权限以及相关服务是否已配置。

请使用与当前安装版本一起发布的文档，不要照搬 EE 或 EE-PVP 的功能入口。
