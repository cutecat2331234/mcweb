McWeb 的授权由服务端根据角色、权限、资源范围和当前状态决定。侧栏和按钮隐藏只用于界面清晰度，不能替代后端权限检查。

## 角色管理

- 创建角色时只授予完成职责所需的权限，并检查受影响用户。
- 权限解释页会显示当前决策和来源；排查访问问题时优先使用该结果。
- 停用或删除角色前，先处理仍依赖它的分配。系统会拒绝破坏完整性的操作或要求迁移。

## 系统设置

设置按注册命名空间和分组呈现。字段旁的当前值、校验错误与安全警告是执行依据；概念和完整步骤请使用本网站对应文档。

基础设置只接受明确列入白名单的站点名称和公开站点 URL。其余入口按论坛、商城、
Minecraft、功能开关、限流和插件设置分组；页面显示的条目数量反映当前版本实际注册的
设置入口。不要根据旧截图或其他版本的侧栏推断某项设置存在。

高风险设置变更前记录原值和变更原因，并准备回滚。插件设置受插件 schema 和版本约束，不要直接修改数据库绕过校验。

## API 密钥与 Webhook

按最小范围创建 API 密钥，绑定需要的用户身份并设置轮换流程。Webhook 密钥只在受保护的配置渠道传递；测试时验证签名、重放防护和失败重试，不在日志中输出明文密钥。
