## 按角色进入

- [用户指南](/docs/user/account-and-security/)：账户安全、Minecraft 身份、社区、附件、商城与支付。
- [工作人员指南](/docs/staff/workspace/)：审核队列、案件、举报、证据和受权限控制的处置。
- [管理员指南](/docs/admin/roles-permissions-settings/)：角色权限、系统设置、网站 CMS、应用和插件。
- [运维指南](/docs/operations/backup-release-rollback/)：部署、备份恢复、Hostd、节点、任务、指标和支付渠道。
- [插件开发](/docs/plugin-development/getting-started/)：Developer Mode、SDK、REST API 和插件市场运维。

## 适用范围

本网站由当前产品仓库中的 Markdown/MDX 构建，只描述站点标题所示版本以及它从上游版本继承的可用能力。

每个页面的版本归属由构建检查校验。请始终使用随当前安装版本构建和发布的文档站。
