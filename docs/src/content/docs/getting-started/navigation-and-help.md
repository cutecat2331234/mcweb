## 从站点进入应用

McWeb 的官网、账户、论坛、商城、工作人员工作台和管理后台有独立入口。切换应用会加载目标应用的页面和导航，但仍使用同一站点的登录身份；不需要为每个应用分别注册。

| 入口 | 用途 |
| --- | --- |
| `/` | 对外官网 |
| `/app`、`/app/account` | CE 个人中心；`/app` 转向个人中心 |
| `/app/account/notifications` | 论坛、商城和系统的统一通知 |
| `/app/forum/latest` | 论坛 |
| `/app/store/products` | 商城 |
| `/app/staff` | 有治理权限人员的工作台 |
| `/admin` | 有后台访问权限人员的管理后台 |
| `/docs/` | 当前版本的正式使用文档 |

应用导航只显示当前功能开关和权限允许的入口。Minecraft 绑定等个人操作从账户进入；托管服务器的运维操作在管理后台中进行。

切换前先保存未完成的表单和草稿。应用间跳转、进入文档或打开外部页面的体验可能与同一应用内切换列表不同，不能依赖页面留在内存中保存输入。

## 打开帮助文档

官网、应用公共导航及管理后台均提供“文档”入口，指向本站的 `/docs/`。也可以直接输入该地址，不需要先进入论坛。文档是独立页面，打开它不会授予业务操作权限。

文档站桌面端左侧是角色分类侧栏，右侧显示当前页面目录。移动端通过页首菜单打开侧栏；页面目录会折叠为正文上方的下拉入口。

## 搜索

页首搜索在浏览器中查询随构建生成的本地索引，不会把查询发送给第三方搜索服务。可使用页面标题、字段名称、错误提示、命令或配置键搜索。

## 深链

每个标题都有锚点，可以复制包含 `#` 的地址直接指向某一步。分享前确认链接的文档版本与接收者安装版本一致。

## 求助时提供什么

请同时提供：

- 当前产品版本（CE、EE 或 EE-PVP）和发布版本号；
- 页面地址与操作角色；
- 界面显示的错误码或完整错误文本；
- 发生时间和可安全公开的请求标识；
- 是否可以稳定复现，以及是否已经发生不可逆操作。

不要在工单或聊天中发送密码、会话 Cookie、API 密钥、Webhook 密钥、私钥或完整凭据配置。
