登录后进入“个人中心”（`/app/account`），查看账户资料、安全状态、未读通知和待处理事项。账户应用独立于论坛和商城；通知、资料和登录安全不需要从论坛页面进入。

## 常用入口

| 要做什么 | 入口 |
| --- | --- |
| 查看账户概览 | `/app/account` |
| 查看通知 | `/app/account/notifications` |
| 修改显示名称和界面语言 | `/app/identity/profile` |
| 管理邮箱、两步验证和账户关闭 | `/app/identity/security` |
| 修改密码 | `/app/identity/security/password` |
| 查看和撤销登录会话 | `/app/identity/sessions` |
| 申请数据副本 | `/app/identity/data-exports` |

## 资料和密码

- 资料页可以修改公开显示名称和界面语言；用户名和邮箱不是该表单的可编辑字段。
- 修改密码需要输入当前密码、新密码和确认密码；已启用两步验证时，还需要验证码或未使用的恢复码。成功后本设备保持登录，其他登录会话全部退出。
- 在“账户安全”申请修改邮箱。确认新邮箱之前，旧邮箱仍用于登录；新邮箱收到确认邮件，旧邮箱收到取消链接。请在页面显示的期限内完成确认。

如果没有发起邮箱变更却收到通知，应使用邮件中的取消入口并检查登录会话，不要把确认链接转发给他人。

## 两步验证与恢复码

1. 在“账户安全”选择“开始设置两步验证”。
2. 用验证器扫描二维码，或手动输入页面提供的密钥。
3. 重新输入账户密码和当前验证码，确认启用。启用后，其他设备会退出登录。
4. 立即复制或下载恢复码，并确认已经妥善保存。恢复码只显示一次，每个码只能使用一次。

重新生成恢复码会立即撤销全部旧码。关闭两步验证会使旧验证器密钥和恢复码失效；敏感操作需要按页面要求重新验证身份。如果站点要求你的账户使用两步验证，需要先完成设置才能继续使用受保护功能。

无法使用验证器时，可以在登录的两步验证页面使用未用过的恢复码。验证器和恢复码都不可用时，从登录页的“无法使用两步验证？”申请邮件恢复，按邮件链接和页面要求验证密码。完成恢复后所有现有会话都会撤销，需要重新登录并重新设置两步验证。

## 登录设备

“活跃会话”列出设备、IP 和最后活跃时间，并标明当前会话。撤销当前会话会立即退出本设备；撤销其他会话会使对应设备失去登录状态。

撤销设备不会更换密码。怀疑凭据泄露时，应修改密码，再检查是否还有未知会话。

## 统一通知

“通知”汇总论坛、商城和系统消息，可按分类、已读状态、类型和时间筛选。同一主题或订单的多条更新可能合并显示，展开后可以逐条查看。

- “查看”会标记该条通知已读，并打开仍有权访问的内容。
- “全部已读”作用于当前筛选范围内的未读通知，不仅是当前页；希望处理所有通知时先清除筛选。
- “清除提醒”将提醒类未读消息标记已读，不会删除业务记录。
- 删除通知无法撤销，但不会删除对应的帖子、订单或案件。

原来的论坛通知地址会转到统一通知页。内容被删除、功能关闭或权限变化后，通知可能显示“内容不可用”，不能通过通知绕过访问限制。论坛与商城的邮件和订阅偏好仍在各自应用的偏好设置中管理。

## 数据导出

选择“申请新导出”后，后台生成私密 ZIP 归档。页面显示等待中、生成中、可下载、失败、已撤销或已过期等状态，以及申请时间、过期时间和各模块记录数量。

在过期前下载；失败或中断的导出按页面显示的“重试”操作处理。超过大小限制时联系支持人员，不要连续申请相同导出。已不需要的归档可以撤销，撤销会移除下载文件，不会删除账户原始数据。申请次数和有效期以页面提示为准。

导出归档可能包含个人信息。下载后请保存在受保护位置，不要转发公开链接。

## 关闭账户

“账户安全”中的关闭账户操作不可逆。需要数据副本时先完成导出并下载，再选择已发布内容的处理方式：保留讨论并改为匿名作者，或申请删除本人发布的社区内容。

关闭会移除或匿名化身份和安全资料，撤销所有登录会话及 API 密钥。内容删除仍受未结举报、证据保全和讨论结构保护等规则约束；订单、付款、退款、审核和审计记录不会随账户一起全部抹除。确认这些结果后，按页面要求验证身份并输入 `DELETE`。
