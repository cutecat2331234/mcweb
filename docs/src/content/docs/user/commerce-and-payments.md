商城提供商品浏览、购物车、地址、订单和通知入口。实际支付方式、币种、库存和退款规则由站点配置。

## 结账

1. 在提交前核对商品、数量、价格、税费和收货信息。
2. 跳转到支付渠道后，不要使用浏览器后退重复创建支付。
3. 返回站点时，以订单详情显示的服务端状态为准，不以单个成功页面或邮件作为最终依据。

## 状态未更新

支付渠道确认可能晚于浏览器返回。订单显示“处理中”时先等待站点完成 Webhook 或对账；不要立即重复付款。若长时间没有变化，请提供订单公开标识和支付时间，切勿发送完整银行卡信息或支付密钥。

## 退款

退款申请、审核、渠道执行和入账可能是不同状态。订单页会显示当前可见状态；退款完成时间取决于支付渠道。工作人员备注只有标记为对客户可见的内容才会出现在用户订单中。
