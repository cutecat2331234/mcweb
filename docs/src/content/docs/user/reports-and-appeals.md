举报用于把具体问题交给管理团队审核；“我的举报”和“复议与申诉”用于私下跟进，不是公开讨论串。

## 提交和跟进举报

1. 登录后，在相关主题、回复、私信、个人资料或其他提供举报按钮的内容上选择“举报”。
2. 选择举报类型，填写有助于判断的具体说明。只提供与你举报的问题有关的事实。
3. 提交后进入“我的举报”（`/app/forum/reports`），保留举报编号并查看详情。
4. 等待审核期间，可在详情中“添加补充”。有证据附件时先上传并等待扫描完成，再按页面操作添加到案件。

“我的举报”只显示你提交的举报。页面提供举报对象类型、你的理由、时间、状态和可公开的处理结果，不展示其他举报人的信息、内部备注或全部处置细节。

| 状态 | 含义 |
| --- | --- |
| 等待审核 | 尚未结案，可继续补充或撤回 |
| 已撤回 | 由举报人关闭，不能重新打开这条举报 |
| 审核完成 | 已完成审核，具体情况以公开结果为准 |
| 未采取措施并关闭 | 未因本次举报采取措施，符合条件时可以申请复议 |
| 采取措施后关闭 | 已按社区规则采取措施，不代表全部细节都对举报人公开 |

撤回不是删除留存记录，也不会撤销工作人员已经完成的独立操作。提交后遇到超时，先查看“我的举报”是否已有记录；遇到限流提示时按提示等待，不要连续重发。

## 哪些决定可以复议或申诉

打开“复议与申诉”（`/app/forum/report-appeals`），先查看“可申请事项”：

- 你是举报人，举报以“未采取措施并关闭”结案时，可以申请复议。
- 你是该举报记录中直接受影响的用户，举报以“采取措施后关闭”结案时，可以申诉此项处置。

这不是对任意账户限制或其他用户案件的通用申诉入口。没有显示可申请事项时，不要借用他人的编号或链接提交；向站点支持人员说明你的情况。

## 提交申请

1. 选择“申请复议”或“申诉此项处置”，创建草稿。
2. 填写希望重新考虑的事实和理由；需要附件时先上传并等待其变为“可用”。
3. 在页面显示的草稿失效时间前选择“提交审核”。创建草稿或仅上传附件不等于已经提交。
4. 在“申请记录”查看状态时间线，并留意[账户通知](/docs/user/account-and-security/#统一通知)中的结果。

同一举报和申请身份已有草稿或正在审核的申请时，应继续处理现有申请。草稿或尚未进入审核的已提交申请，可在页面允许时取消；取消后的申请不能重新打开。内容或状态已被更新时，刷新详情后再操作。

## 证据附件与隐私

证据附件需要通过安全扫描，数量和大小以页面提示为准。扫描中、隔离或上传失败的文件不能当作已经递交的可用证据；扫描超时后先刷新状态，不要重复上传同一文件。

尚未加入案件的附件可在页面允许时丢弃。已经加入案件的证据按保留规则处理，不能保证可以撤回或立即删除。申请人只能看到向自己开放的材料，审核人员的内部证据不会随结果全部公开。

## 理解结果

“维持原决定”表示本次复核保留原结论；“撤销原决定”表示本次复核改变了该结论。撤销结果不会自动撤销其他独立的站务处置，也不会自动恢复被删除的内容或解除禁言、封禁。需要后续处理时，把申请编号和结果交给有相应权限的工作人员。
