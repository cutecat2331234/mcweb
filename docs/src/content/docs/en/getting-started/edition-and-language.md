This site belongs to **McWeb Community Edition (CE)**. It covers the shared platform: accounts, community, commerce, Minecraft integration, the website CMS, staff moderation, operations, and trusted plugins.

CE includes the separate account application and unified notifications, report reconsideration and appeals, content recovery and retention, managed Minecraft world backup and restore, and the embedded administrator Sidekiq console. Each operation still requires its own permissions and prerequisites.

EE real-time channels and enterprise collaboration are outside this edition. EE-PVP applications, testing, Tier, ranking, and season workflows are also outside this edition.

## Application language

Use the application language selector or edit your profile to choose Simplified Chinese or English. A choice saved while signed in also updates your account preference. Visitors may initially see their previous selection or browser language. Changing the interface language does not translate user content, website articles, plugin text, or external pages.

## Documentation language

Simplified Chinese is the default documentation language at `/docs/`. English is published progressively under `/docs/en/`. Missing English translations fall back to the Simplified Chinese source with a visible notice; that notice does not mean an English translation is available.

The documentation language selector is separate from the business applications' interface language. Commands, paths, and configuration keys remain unchanged between languages.
